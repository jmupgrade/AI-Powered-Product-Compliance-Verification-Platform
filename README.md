# AI-Powered-Product-Compliance-Verification-Platform
This project showcases how AI-powered data extraction and automated verification can eliminate manual busywork from product compliance workflows — reading Style #, Size, and UPC data directly from hang tag images and purchase order PDFs, then cross-referencing them to catch mismatches before production. I built it to demonstrate how combining OCR pipelines with deterministic matching and human-in-the-loop review creates reliable, scalable systems that catch the one wrong digit that would otherwise send thousands of units back to the warehouse.
